# คู่มือใช้งาน

ระบบบริหารจัดการคำขอและทะเบียนบริการ Hosting / Virtual Server

## ผู้ขอใช้บริการ

1. เปิดหน้าแรก แล้วเลือกยื่นคำขอใช้บริการ
2. กรอกข้อมูลผู้ขอและผู้พัฒนา ระบุวัตถุประสงค์ ช่วงวันที่ และบริการที่ต้องการ
3. เลือกแพ็กเกจที่ตรงประเภทบริการ หรือระบุทรัพยากรตามแบบฟอร์ม
4. ระบุโดเมนและหน่วยงาน แนบเอกสารรายละเอียดระบบ ไฟล์หลักรับ PDF/DOC/DOCX/ZIP ไม่เกิน 10 MB; หลักฐานประกอบรับ PDF/JPG/JPEG/PNG ไม่เกิน 10 MB
5. เลือกยินยอมชำระหรือขอยกเว้นค่าธรรมเนียมพร้อมเหตุผล ยอมรับข้อกำหนดและแนบภาพลายเซ็นไม่เกิน 2 MB
6. ส่งคำขอและเก็บเลขที่ REQ-... ที่ระบบแสดง หากมีข้อผิดพลาดให้แก้ตามข้อความและเลือกไฟล์ใหม่ตามที่ browser ต้องการ

ระบบยังไม่มีหน้าติดตามสถานะด้วยตนเอง ให้ติดต่อเจ้าหน้าที่พร้อมเลขที่คำขอ ช่องทางและผู้ติดต่อให้มหาวิทยาลัยกำหนดก่อนเผยแพร่ การกรอกรหัสบุคลากรไม่ได้เป็นการยืนยันตัวบุคคล เจ้าหน้าที่ต้องตรวจเอกสารและความถูกต้องตามขั้นตอนของมหาวิทยาลัย

## เจ้าหน้าที่: พิจารณาคำขอ

1. เข้าสู่ระบบที่ `/login` ด้วยบัญชีที่ผู้ดูแลสร้างให้
2. เปิดรายการคำขอ ค้นหาชื่อหรือรหัสผู้ขอ และเลือกสถานะที่ต้องการ
3. เปิดรายละเอียด ตรวจข้อมูล ทรัพยากร โดเมน เอกสารและลายเซ็น
4. แก้ข้อมูลคำขอเมื่อจำเป็น แล้วอนุมัติเฉพาะคำขอที่รอพิจารณา
5. หลังอนุมัติจึงสร้างทะเบียนบัญชีได้ ระบบรับชื่อผู้ดำเนินการจากบัญชีที่ล็อกอินและป้องกันสร้างซ้ำในคำขอเดียวกัน

การอนุมัติเป็นชั้นเดียวโดยเจ้าหน้าที่ ไม่ได้ยืนยันการรับชำระเงิน ข้อมูลเลขใบเสร็จเก่าที่เห็นเป็นข้อมูลอ้างอิงเดิม ต้องตรวจแยกกับฝ่ายการเงิน การบันทึกทะเบียนบัญชีไม่สร้างบัญชีหรือพื้นที่บน Plesk ให้ดำเนินการบน Hosting ตามขั้นตอนหน่วยงานด้วย

คำขอที่สร้างบัญชีแล้วจะหายจากรายการคำขอรอสร้างบัญชี สามารถเปิดคำขอต้นทางจากรายการบัญชีได้ รหัสผ่านบัญชีบริการแสดงครั้งเดียวหลังสร้าง ให้ส่งต่อผ่านช่องทางที่หน่วยงานกำหนด รหัสผ่านที่นำเข้าจากข้อมูลเก่าไม่ใช่รหัสผ่าน Plesk จริง

## เจ้าหน้าที่: จัดการบัญชีและโดเมน

เปิดรายการบัญชีเพื่อค้นหา กรองสถานะ หรือเรียงวันหมดอายุ เมนูเพิ่มเติมมีแก้ไขบัญชี ต่ออายุ/ประวัติ เปิดหรือระงับ และลบ

แก้ไขบัญชีโดยปล่อยช่องรหัสผ่านว่างเมื่อไม่ต้องการเปลี่ยนรหัส สถานะและวันหมดอายุในหน้านี้เป็นข้อมูลทะเบียน ไม่ได้ส่งคำสั่งไป Hosting รายการโดเมนแก้ชื่อและหน่วยงานได้ แต่ไม่ได้เปลี่ยน DNS จริง

## เจ้าหน้าที่: ต่ออายุ

1. เปิดบัญชีผู้ใช้บริการ → เมนูเพิ่มเติม → ต่ออายุบริการ / ประวัติ
2. ตรวจชื่อบัญชี ผู้ขอ สถานะ และวันหมดอายุเดิม
3. เลือกวันหมดอายุใหม่ ระบบแนะนำเพิ่ม 1 ปีจากวันเดิม หรือจากวันนี้เมื่อหมดอายุแล้ว วันที่ใหม่ต้องมากกว่าวันเดิมและหลังวันนี้
4. ใส่หมายเหตุหรือเลขเอกสารอ้างอิง แล้วกดยืนยัน
5. ตรวจข้อความสำเร็จและประวัติซึ่งแสดงวันเดิม วันใหม่ ผู้ดำเนินการและหมายเหตุ

บัญชีสถานะ expired เปลี่ยนเป็น active หลังต่ออายุ ส่วน disabled ยังคงถูกระงับ ถ้าข้อมูลถูกเปลี่ยนโดยเจ้าหน้าที่อีกคน ระบบจะให้โหลดหน้าใหม่ การต่ออายุมีผลเฉพาะบัญชีที่เลือก ไม่เปลี่ยนระยะเวลาโครงการหรือบัญชีอื่นของคำขอเดียวกัน

หลังบันทึกให้เจ้าหน้าที่ดำเนินการต่ออายุบนเครื่อง Hosting จริงตามกระบวนการหน่วยงานแยกต่างหาก

## เจ้าหน้าที่: บัญชีผู้ดูแลและการลบ

เจ้าหน้าที่ที่เปิดใช้งานทุกบัญชีเข้าถึงหลังบ้านได้เท่ากัน รวมถึงเอกสารแนบและการจัดการเจ้าหน้าที่ จึงควรสร้างบัญชีเฉพาะผู้ที่หน่วยงานมอบหมาย เมื่อปิดใช้งานบัญชี การเข้าหลังบ้านครั้งถัดไปจะถูกปฏิเสธ แม้มี session เดิมอยู่ เจ้าหน้าที่ปิดบัญชีตนเองไม่ได้

การลบไม่มีถังขยะ การลบคำขอลบข้อมูลลูกและประวัติที่เกี่ยวข้อง การลบบัญชีสุดท้ายของคำขอลบโดเมนในทะเบียนของคำขอนั้นด้วย ให้ใช้ระงับบัญชีเมื่อเพียงต้องการหยุดสถานะใช้งานและยังต้องเก็บประวัติ

## สคริปต์สาธิต 5–10 นาที

ใช้ฐานข้อมูลสมมติแยกจากข้อมูลจริง ยื่นคำขอหนึ่งรายการ เปิดรายละเอียดในหลังบ้าน อนุมัติ สร้างบัญชี แก้ชื่อบัญชี ต่ออายุ ดูประวัติ แล้วระงับ ตรวจว่าข้อมูลยังค้นหาได้ ปิดท้ายด้วยการอธิบายว่าระบบยังไม่ได้เชื่อมคำสั่ง Plesk และแสดงข้อจำกัดในเอกสารส่งมอบ
